# 📊 Sales Data Analysis

## Project Overview

This project analyzes a simple sales dataset using Python and Pandas.

The project loads sales data from a CSV file, explores the dataset, handles missing values and duplicate records, calculates sales metrics, identifies the best-selling product, and generates a formatted sales report.

## 🎯 Objectives

- Load sales data using Pandas
- Explore the dataset
- Identify missing values
- Remove duplicate records
- Calculate total revenue
- Calculate total units sold
- Find the best-selling product
- Analyze product and regional performance
- Generate a formatted sales report

## 🛠️ Technologies Used

- Python
- Pandas
- CSV
